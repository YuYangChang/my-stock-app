Yahoo 股市 API 數據介接說明

1. Yahoo Finance API 格式 (台股)：
台股上市公司代碼需加上 .TW (如台積電為 2330.TW)。

2. 即時 K 線與成交金額 API Endpoint：
https://query1.finance.yahoo.com/v8/finance/chart/2330.TW?range=3m&interval=1d

3. CORS 跨域解法 (Proxy Bridge Example):
由於瀏覽器同源策略，前端直接調用會觸發 CORS 封鎖，建議通過 CORS Proxy 或 Node.js 後端轉發。

JavaScript API Fetch 範例代碼 
async function fetchTWStock(symbol = '2330.TW') {
  const proxy = 'https://corsproxy.io/?';
  const target = `https://query1.finance.yahoo.com/v8/finance/chart/${symbol}?range=1m&interval=1d`;
  
  const res = await fetch(proxy + encodeURIComponent(target));
  const data = await res.json();
  const result = data.chart.result[0];
  
  // 計算最新成交金額 (單位: 億元)
  const meta = result.meta;
  const lastPrice = meta.regularMarketPrice;
  const lastVolume = meta.regularMarketVolume; // 張數
  const turnoverInHundredMillion = ((lastPrice * lastVolume) / 100000).toFixed(2);
  
  return {
    price: lastPrice,
    turnover: turnoverInHundredMillion,
    quotes: result.indicators.quote[0]
  };
}
